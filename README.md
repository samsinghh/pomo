# pomo

pomodoro timer for macOS, run it from the terminal and a small floating
timer pops up in the corner of your screen.

## Install

```sh
git clone https://github.com/samsinghh/pomo.git
cd pomo
make install
```

## Usage

```
pomo <work-minutes> <break-minutes>
```
